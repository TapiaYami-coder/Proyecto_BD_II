# Proyecto_BD_II
# OBRAS Y CONTROL

**Sistema Web de Gestión y Control de Construcciones**

## Descripción del proyecto

OBRA CONTROL es un sistema web desarrollado con el propósito de facilitar la administración, organización y supervisión de proyectos de construcción, tanto para empresas constructoras como para constructores independientes.

La plataforma permite centralizar la información relacionada con las obras, proporcionando herramientas para gestionar proyectos, trabajadores, proveedores, materiales de construcción, presupuestos, gastos, compras y avances de obra.

El sistema busca optimizar el control de los recursos humanos, materiales y económicos, permitiendo llevar un seguimiento organizado de cada proyecto y facilitando la toma de decisiones mediante información clara y reportes administrativos.

Además, contará con diferentes tipos de usuarios, como administradores, encargados de obra, trabajadores y proveedores, cada uno con funciones y permisos específicos según su participación dentro del sistema.

## Objetivo general

Desarrollar una aplicación web que permita gestionar y controlar proyectos de construcción mediante una base de datos relacional, facilitando la administración de recursos, el seguimiento de actividades y el control financiero de las obras.

## Módulos principales

- **Gestión de proyectos:** registro y administración de obras de construcción.
- **Gestión de trabajadores:** registro, organización y asignación del personal.
- **Gestión de materiales:** administración y control de materiales de construcción.
- **Gestión de proveedores:** registro y administración de proveedores.
- **Gestión de presupuestos:** planificación y control de presupuestos por proyecto.
- **Gestión de gastos:** registro y seguimiento de los gastos realizados.
- **Control de compras:** administración de compras y adquisición de materiales.
- **Seguimiento de obras:** registro de etapas y avances de construcción.
- **Reportes administrativos:** generación de información sobre proyectos, recursos y gastos.

## Tipos de usuarios

- Administrador.
- Encargado de obra.
- Trabajador.
- Proveedor.
